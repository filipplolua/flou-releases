# FLOU — сборки и обновления

Здесь лежат только **готовые сборки** приложения FLOU и манифест обновлений.
Исходного кода тут нет.

- `latest.json` — манифест, который опрашивает приложение
- APK-файлы — во вкладке [Releases](../../releases)

Приложение проверяет `latest.json`, сравнивает `versionCode` со своей сборкой и,
если версия новее, предлагает обновиться. Установку всегда подтверждает
пользователь.
